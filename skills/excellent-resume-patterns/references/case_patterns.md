# 去标识化简历案例模式

## 使用边界

本文件只保留可复用的职业路径、证据结构和写作方法。现存材料保留职业路径和表达结构，不包含完整原简历。数字用于示范“如何量化”，不是用户可复用的个人事实。

## A. 定量商科 + 技术双背景 → 商业分析 / BI / 数据产品

**背景画像**

- 商科分析与计算机交叉背景。
- 多段互联网商业分析、BI、策略运营和咨询经历。
- 强项是把“业务问题—数据—策略实验—结果”串成闭环。

**最强证据结构**

1. 数据治理：清理和合并指标，重构 Pipeline/Dashboard，降低云成本。
2. 经营分析：补贴、门店、预算或 ROI 监控，问题定位后推动策略调整。
3. 自动化：用 Python/SQL 替代人工流程，节省时间并提高自助分析能力。
4. 咨询研究：提出业务假设，通过回归、对标和资料研究验证。
5. 0-1 项目：团队规模、时间限制、用户调研、MVP 和模型落地。

**可复用 bullet 骨架**

- `指标治理：识别 [可弃用/冗余] 指标，重构 [Pipeline/看板]，支持 [成本/效率] 改善。`
- `经营归因：将监控粒度细化到 [对象]，从 [维度] 定位异常，推动低效 [对象] 减少。`
- `策略实验：按 [分桶/分层] 测算 ROI，协同 [团队] 执行 A/B Test，确定差异化策略。`
- `自动化：用 [语言/工具] 自动化 [流程]，将 [工作量] 降低，并沉淀可复用看板。`

**参考价值**

适合投商业分析、BI、策略分析和数据产品。核心不是堆工具，而是证明分析能改变预算、补贴、成本或运营动作。

## B. 理工科研背景 → AI 产品 / 模型评测

**背景画像**

- 强数理和科研训练，缺少传统产品 title。
- 通过 AI 内容安全、评测平台或 RAG 项目完成岗位迁移。

**最强证据结构**

1. 场景拆解：明确 AI 生成、审核或知识检索中的具体风险。
2. 产品闭环：样本输入 → 标签/规则 → RAG/模型 → 人工复核 → badcase 回流 → Prompt 优化。
3. 指标体系：命中率、误判率、漏判率、人工复核率、输出通过率。
4. 科研迁移：目标、变量、验证路径、结果复盘。

**可复用 bullet 骨架**

- `围绕 [AI 场景] 拆解 [风险/任务]，设计 [输入—模型—复核—反馈] 闭环。`
- `建立 [准确率/误判率/人审率] 指标体系，支撑模型效果比较和规则迭代。`
- `将 [科研方法] 迁移到产品验证，形成“假设—验证—复盘”的决策流程。`

**参考价值**

适合非产品科班转 AI 产品。关键是把科研能力翻译成产品问题定义、实验设计和评测闭环。

## C. 语言/文科背景 → 增长 / 电商 / 策略运营

**背景画像**

- 原专业与互联网无关，通过多段运营实习完成转岗。
- 项目覆盖推荐、游戏化、行业运营和广告投放。
- 最大特点是结果量化非常充分。

**最强证据结构**

1. 用户感知：内容、模板、权益和决策信息优化。
2. 基础体验：断流、满页率、刷新、供给、转化链路。
3. B 端运营：商家分层、政策透传、活动报名和商业化。
4. C 端增长：拉新、CVR、停留、ROI 和 GMV。
5. 渠道拓展：开户、建联、社群和客户维护。

**可复用 bullet 骨架**

- `围绕 [用户问题] 重构 [链路/页面/机制]，改善 [CTR/CVR/停留/满页率]。`
- `按 [头部/腰部/长尾] 分层运营 [商家/用户]，通过 [政策/活动/触达] 提升 [GMV/ROI]。`
- `设计 [活动机制 + 权益 + 渠道触达]，形成拉新、转化、复购和复盘闭环。`
- `从公海/竞对/存量对象拓展增量，完成 [建联/开户/入驻] 并沉淀 SOP。`

**参考价值**

适合文科转运营、增长、电商和策略产品。核心是把感性运营写成可测量的业务链路。

## D. 心理学/社科背景 → AI 产品 / B 端技术产品

**背景画像**

- 用户研究、访谈、交互和实验设计基础强。
- 通过云产品、Agent 平台或教育产品项目补齐技术产品经验。

**最强证据结构**

1. 用户研究：访谈、问卷、体验地图、旅程和需求优先级。
2. B 端交付：SDK、API、控制台、文档、客户接入和上线。
3. Agent 方案：产品推荐、文档问答、商机发现、邮件自动化等。
4. 业务结果：接入效率、售前效率、转化率、成本。
5. 复杂项目：竞品拆解、功能原子化、原型、流程图和影子测试。

**可复用 bullet 骨架**

- `通过 [访谈/问卷] 识别 [用户] 在 [环节] 的流失，转为 [Agent/功能] 方案。`
- `使用 [LKE/自研框架] 搭建 [Agent/Workflow]，接入 [Prompt/知识库/API]，完成 [上线结果]。`
- `独立负责 [需求数量] 从调研到上线，优化 [文档/控制台/接入]，提升 [效率/转化]。`
- `完成 [竞品数量] 功能拆解和 [用户数量] 验证，输出 PRD、流程和原型。`

**参考价值**

适合心理学、社科和用户研究背景转 AI/B 端产品。核心是证明用户研究能转化为技术产品和业务结果。

## E. 管理科学/工科 → 数据分析 / 商业分析（早期经历型）

**背景画像**

- 管理科学、工程或统计背景。
- 实习时间较早，但工具链、模型和分析任务完整。

**最强证据结构**

1. SQL/Hive 取数与自动化日报。
2. 用户流失、召回和留存分析。
3. 库存、仓容、SKU 或供应链优化。
4. 聚类、预测、分类和仿真模型。
5. 科研、专利或竞赛成果。

**可复用 bullet 骨架**

- `从 [Hive/数仓] 提取业务数据，搭建 [日报/看板]，将手工更新改为自动化。`
- `排查 [指标] 异常，对用户/对象分层并推动召回或运营方案。`
- `通过 [模型] 验证 [业务假设]，将结果转化为 [预测/预警/库存/营销] 策略。`

**参考价值**

适合把较早或普通的分析经历写得扎实。强调方法、工具、交付物和结果，而不是公司品牌。

## F. 非技术专业 + 经历较杂 → 产品 / 运营 / 项目管理

**背景画像**

- 专业与目标岗位不直接相关。
- 经历横跨产品、运营、创投和咨询。
- 用“背景—目标—行动—结果”统一不同经历。

**最强证据结构**

1. 产品平台：迁移、竞品、工作流、配置和项目排期。
2. AI 模拟面试：埋点漏斗、ICE、Prompt 和功能设计。
3. 创投项目：项目转化、行研报告、SOP 和周期缩短。
4. CRM/教培：拉新、咨询、成交、续费和收入。
5. 钱包/开屏：体验地图、竞品、原型、埋点和灰度实验。

**可复用 bullet 骨架**

- `背景：明确旧流程的业务损失；目标：定义要改善的指标。`
- `行动：写清调研、方案、跨团队推进和上线过程。`
- `结果：同时给出规模、效率、质量或收入变化。`

**参考价值**

适合经历方向多、需要建立统一主线的候选人。

## G. 供应链/物流 → 供应链 / 商业分析 / 运营分析

**背景画像**

- 供应链、采购、物流或工业工程背景。
- 实习横跨供应链、商业分析、数据和产品。

**最强证据结构**

1. 计划与交付：订单、交付、质量、库存和成本 KPI。
2. 供应商管理：绩效、风险、质量和价格。
3. 用户与流量分析：预订、留存、流失和渠道转化。
4. 数据看板：实时指标、运营数据和决策支持。
5. 跨境电商：货盘、库存、爆品和市场趋势。

**可复用 bullet 骨架**

- `按“计划—交付—质量—库存—成本”管理 [范围]，跟踪 [KPI]。`
- `建立供应商 [绩效/风险] 评估框架，综合分析 [质量/价格/交付/财务]。`
- `分析 [用户/渠道/商品] 数据，输出看板或报告并支持 [采购/运营] 决策。`

**参考价值**

适合供应链转商业分析或运营分析。避免只写岗位职责，必须补结果和决策价值。

## H. AI 科班 → AI 产品 / 数据产品 / 大模型产品

**背景画像**

- AI、计算机或理工科背景。
- 有多段大模型、Agent、数据产品或 B 端产品经历。
- 项目覆盖平台、公安、地图数据、教育或商业化。

**最强证据结构**

1. ReAct/Agent/Workflow/MCP/RAG 的机制理解。
2. 平台产品：应用市场、工具调用、节点和知识库。
3. 客户与商业化：客户申请、交付、续签、签单额。
4. 模型效果：准确率、可用率、召回率、准确率和成本。
5. 数据治理：判重、清洗、下线低质数据和平台建设。

**可复用 bullet 骨架**

- `主导 [Agent/Workflow] 落地，定义 [能力/节点/工具]，将 [任务] 自动化。`
- `设计 [Prompt/评测/人审] 机制，使 [准确率/可用率] 改善。`
- `推动平台支持 [应用/MCP/API/知识库]，实现 [调用量/收入/客户] 增长。`
- `优化 [算法/判重/数据流程]，将 [召回/准确/质量] 提升并下线低质数据。`

**参考价值**

适合 AI 科班把技术理解转成产品、交付和商业结果。技术词必须绑定用户和价值。

## I. 工科转数据分析 → 数据分析 / 策略分析

**背景画像**

- 机械、船舶、工程或理工科背景。
- 通过数据实习和项目完成转岗。

**最强证据结构**

1. HQL/SQL/Python/MySQL/Spark。
2. AB 实验、分桶、定价和策略效果。
3. 安全、拼车、广告或运营分析。
4. 报表、Dashboard 和自助查询工具。
5. 爬虫、文本处理、可视化和竞赛。

**可复用 bullet 骨架**

- `使用 [SQL/HQL/Python] 支持 [地区/业务] 分析，搭建 [围栏/报表/看板] 并推动迭代。`
- `设计 AB 实验和分桶策略，分析 [效果/约束]，形成 [定价/运营] 建议。`
- `制作 [报表数量] 可视化工具，支持业务自助查询并将 [指标] 改善。`

**参考价值**

适合工科转数据分析。用工具链、实验、决策和业务结果证明能力。

## J. 商科 + 数学 → 数据分析 / 国际化策略 / 商业分析

**背景画像**

- 商科与数学/统计交叉，具备较强的量化基础。
- 实习覆盖国际化出行、电商经营和本地生活。

**最强证据结构**

1. 异常归因：漏斗、产品、反作弊和支付多维定位。
2. 实验分析：供需、ROI、补贴、触达和司机行为。
3. 经营监控：达人分层、流量类型、GMV 和退款。
4. 数据基建：90%+ 指标报表和自动化。
5. 目标管理：城市系数、目标分配、考核核对和排名。

**可复用 bullet 骨架**

- `从 [漏斗] 定位 [指标] 异常，进一步从 [产品/风险/支付] 找到原因并量化影响。`
- `从 [供给/ROI/补贴/效果] 分析实验，提出 [触达/激励] 优化建议。`
- `按 [人群/场域/流量] 拆解业务，识别负向影响并沉淀归因 SOP。`
- `搭建高覆盖率指标报表，将 [周报/分析] 时间缩短。`

**参考价值**

适合数据分析、国际化运营和经营分析。核心是异常发现、归因、实验和决策闭环。
