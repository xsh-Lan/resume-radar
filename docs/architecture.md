# 简历雷达 V2

`skills/resume-coach/SKILL.md` 是可发现入口，其他四个 Skill 为专业模块。岗位与事实分析 → 差距及关键追问 → 全量逐句处理 → 聚焦复核 → 文件校验与渲染。

`workflow.py` 建立来源单元、校验引用与覆盖、保存快照；它不推断能力。模型依据诊断标准填写结果并记录依据；语义判断需要对照原始材料。`render_report.py` 只展示通过机械检查的数据，不自动断言没有编造。

运行目录在用户工作区，用户资料不保存到插件安装目录。文件交接契约见 `standards/data-contract.md`。脱敏由显式命令处理本次目标，不依赖宿主钩子或扫描历史目录。
