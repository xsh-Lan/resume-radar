# 验证与内容评测

`python evals/run_eval.py` 运行三模式流程与来源/覆盖/数值/贡献/确认状态等行为验证。`--run-dir` 可额外验证一份已分析目录。这些验证不用模型API，也不衡量诊断是否比旧版本深入。

`make_example.py --output-dir <新目录> --mode jd|direction|explore` 创建明确标注的虚构教学数据，用于演示交接及报告；手写诊断不是独立模型效果测量。

实际内容评测使用 `content_cases.json` 与 `content_rubric.md`，保存真实生成的输入、输出和反馈。相同模型、原始材料、工具和追问预算下比较直接提示、旧聚合、V2；交换盲评顺序并允许平局。另留未调规则的案例验证，记录每个模块加/不加的效果。通过单元验证不能宣称内容质量提高了某个百分比。
